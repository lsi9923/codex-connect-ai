# Task Card Agent Ops Goal

## Goal
직원별 작업 카드를 클릭했을 때 직원 운영 상태를 바로 관찰할 수 있게 만들고, Writer와 Researcher 픽셀 자리를 CEO 방 밖으로 옮긴다.

## Checklist
- [x] 작업 카드 클릭 시 선택 직원이 바뀌고 카드가 선택 상태로 표시된다.
- [x] 각 작업 카드 안에 업무 관찰, 장기 기억 저장, 스킬 개선 제안, 예약 실행 대기 상태가 보인다.
- [x] 선택된 작업 카드의 운영 루프 상세가 작업 카드 섹션 안에서 표시된다.
- [x] Writer와 Researcher 기본 자리가 CEO 방 밖 일반 업무 구역으로 이동한다.
- [x] 기존 프로필/스킬 편집 기능은 유지된다.
- [x] `npm test`와 `npm run build`가 통과한다.
- [x] 브라우저에서 카드 클릭과 좌표 변경을 확인한다.

## Exit Conditions
- 작업 카드 9개 모두 운영 루프 신호를 표시한다.
- 작업 카드 클릭 후 선택 직원의 업무 관찰/기억/스킬/예약 값이 보인다.
- Writer/Researcher가 CEO 방 하단 내부가 아니라 바깥 업무 구역에 배치된다.
- 변경 사항을 GitHub `main`에 푸시한다.
